# Mobile Screen Recipe

## Base
- Background: Paper
- Horizontal page padding: 16
- Major vertical section gap: 24
- Related-item gap: 8–12
- Card radius: 12
- Large brand panel radius: 16
- Bottom sheet radius: 20

## Cards
Default card:
- white fill
- 1px divider border
- no shadow

Use tinted `Orange 50` / `Orange 100` only for selected/promotional/status-adjacent areas.

## Lists
Prefer one structured list with separators over a separate card per row.

## Forms
- labels remain visible
- focused border uses orange500
- 48px minimum height
- helper/error text below control

## POS flows
Prioritize speed:
- minimal decoration
- large totals
- obvious primary action
- persistent cart state where appropriate
- avoid animations that delay scanning or checkout

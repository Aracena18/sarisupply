# Accessibility

- Target WCAG AA contrast for text.
- Use `#111111` on `#F26A1B` for the standard bright primary button.
- Use white on `#C84A00` when a white-on-orange treatment is required.
- Never use color alone to communicate success, warning, failure, or selected state.
- Use text + icon/state wording.
- Minimum interactive target: 48×48 logical pixels.
- Support text scaling without clipping.
- Preserve visible keyboard/focus states on web/desktop.
- Keep error copy adjacent to the relevant control.

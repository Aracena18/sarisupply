# AI-Slop Guardrails

SariSupply must not look like a generic AI-generated SaaS dashboard.

## Ban by default
- purple-blue gradient blobs
- glassmorphism
- enormous radii on every object
- glowing shadows
- random 3D icons
- emoji as navigation
- decorative sparkles
- five different card styles on one screen
- centered marketing copy in dense operational flows
- rainbow analytics without semantic purpose

## Preferred
- strong information hierarchy
- warm paper background
- white working surfaces
- restrained orange
- 1px dividers
- one icon system
- 8pt spacing rhythm
- tabular figures
- structured lists and grids
- only one dominant action per task region

## Premium means
Precision, restraint, spacing, typography, and material hierarchy.

Premium does **not** mean adding effects.

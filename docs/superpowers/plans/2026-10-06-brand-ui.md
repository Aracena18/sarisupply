# SariSupply mobile brand UI refactor

The operator requested the supplied SariSupply Design System v1 board and assets
for POS, Admin, and Driver. This supersedes the previous teal storefront styling.

## Goal and scope

Make the existing phone workflows calmer, readable, and consistent with Warm
Utility: paper backgrounds, white working surfaces, ink typography, restrained
orange actions, and semantic status colors with text labels.

- Integrate supplied SVG brand, navigation icons, tokens, and components in the
  shared design-system package.
- Bundle licensed Instrument Sans for consistent Android rendering.
- Theme existing inputs, actions, app bars, navigation, overlays, and status
  surfaces. Preserve 48px targets and system text scaling.
- Reduce crowded POS toolbars and use labeled Admin workspace navigation.
- Preserve Admin search and opened workspace state while switching destinations;
  Android Back returns to Applications before leaving the workspace.
- Use neutral report cards with readable labels and tabular totals.
- Adapt Driver route metadata and delivery quantity controls to narrow phones.

## Invariants

Keep authentication, App Check, tenant/device authorization, Firebase gateways,
domain calculations, operation IDs, local SQLite data, outbox handling, and
retry behavior intact. Change presentation and navigation only. Do not add
placeholder destinations or enable unavailable actions.

## Verification and limits

Use formatting, analysis, architecture checks, targeted UI regressions, visual
inspection of representative screenshots, and Development Android APK builds.
The comprehensive emulator/harness run is deferred under the repository's
build-focused instructions. Live phone acceptance requires the operator's
hands-on review; static analysis and builds do not establish backend readiness.
